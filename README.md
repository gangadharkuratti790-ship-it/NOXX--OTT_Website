# 🎬 NOXX OTT Platform

## 📌 Overview

NOXX is a modern OTT (Over-The-Top) platform UI/UX project designed and developed as part of my college coursework.
The project focuses on creating a clean, user-friendly, and visually engaging streaming interface inspired by platforms like Netflix and Prime Video.

---

## 🎯 Features

* 🎥 Attractive homepage with featured content
* 🔍 Search and browsing UI (design-based)
* 📱 Responsive layout (mobile + desktop)
* 🎨 Clean and modern UI/UX design
* 🎬 Movie/series thumbnails and sections
* 🧭 Smooth navigation experience

---

## 🛠️ Technologies Used

* UI/UX Design Principles

---

## 🧠 What I Learned

* Designing user-friendly interfaces
* Structuring frontend projects properly
* Basics of UI/UX thinking and user flow

This project was initially developed as a college assignment and later improved with better UI design and structure.
